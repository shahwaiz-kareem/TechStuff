# Project: Singtronic E-Commerce Platform Refactor & Optimization

Reengineered and optimized **Singtronic**, a popular open-source e-commerce platform, to improve user engagement, frontend performance, and core functionality. 

## Key Achievements

### 🎨 UI/UX Modernization
* **Led a complete refactor** of the open-source platform's legacy frontend.
* **Transitioned unresponsive interfaces** into a modern, mobile-first design.
* **Implemented Tailwind CSS** to ensure seamless responsiveness across all device sizes.

### ⚡ Performance Optimization
* **Accelerated page load times by 60%** across the entire platform.
* **Eliminated redundant UI library dependencies** to drastically reduce bundle size.
* **Streamlined the frontend codebase** for better maintainability and cleaner architecture.

### ⚙️ Feature Engineering & Bug Fixes
* **Engineered advanced category filtering** to improve product discoverability.
* **Built a robust wishlist feature** from scratch to boost user retention.
* **Resolved a critical authentication system bug** to secure user login and registration flows.

## Tech Stack
* **Frontend:** HTML5, CSS3, Tailwind CSS, JavaScript (ES6+)
* **Platform Baseline:** Singtronic Open-Source E-Commerce
